## Notes
- Acceptance criteria all met and verified: cache-hit 200 ranked+cited; cache-miss 202 + pollable `task_id`; second same-role request served from Redis with DB/resolver hit exactly once (`test_cache_miss_hits_db_then_second_request_served_from_redis` spy-asserts `db.sessions == 1`, `resolver.calls == 1`); `/gap` requires auth, rejects guests (403), degrades to 200 for ok/profile_missing and 202 for unmined role with no 500; both routes registered in `app/main.py`; no `GET/POST /api/jobs` listing route; mining only ever via `mine_role_task.apply_async` (`enqueue_mine_role`), never awaited on the request path.
- Security: correct. The untrusted `{role}` path param never reaches a server-side fetch on the request path — all crawling is deferred to the Celery mine (§7.5), so no SSRF surface here. Role string is used only as a Redis key and a SQLAlchemy-parameterized `canonical_role` lookup (no injection). No arbitrary execution. Auth gating is correct: `resolve_optional_user` never raises (optional), `require_auth` + explicit `user_id is None → 403` blocks guests on `/gap`.
- Quality/DRY: good reuse — `resolve_canonical_role` (single taxonomy normalizer), `rank_requirements`/`_to_skill_gap` extracted and shared with the gap diff, `SkillsGapService` reused, `CvUploadResponse`-shape 202 handle reused, `StoreRedis` seam reused for the cache adapter, generic `/api/jobs/status` reused (no second status endpoint). Ports (`RoleProfileCache`/`CanonicalRoleResolver`/`MineRoleEnqueuer`) keep the service driver-free and unit-testable. Router→Service→Repository layering respected.
- Cache-key decision (normalize raw param, not canonical, so a Redis hit short-circuits before the Postgres-backed canonicalization) is sound and correctly documented; the only cost is two cheap cache entries for two spellings of one role — harmless.
- `tests/test_roles_service.py tests/test_roles_api.py tests/test_skills_gap.py` → 27 passed locally. Working tree also contains unrelated sibling-P6 task changes (graph.py, internet_search.py, deleted `models/jobs.py`, etc.) — out of scope for this review.
