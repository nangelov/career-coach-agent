## Notes
- **Acceptance criteria: all met.** `ProfileSchema`/`ExperienceItem`/`EducationItem` cover skills/experience/education/goals, documented as the `profiles.data` (§4) shape; `model_dump()` is plain str/list → JSON-serializable for the P5-04 JSONB write. Structuring uses native forced tool-calling (no regex/ReAct) with an injected `LLMCompleter`. Partial CVs degrade via schema defaults (verified: `test_missing_sections_default_to_empty`, `test_partial_experience_item_is_kept_not_dropped`, `test_empty_arguments_yield_an_empty_profile`). Every unrecoverable path (no tool call / bad JSON / non-object args / schema-invalid payload / `LLMError`) raises the single `ProfileStructuringError` (5 error-path tests). Empty-document short-circuit skips the LLM call (`test_empty_document_short_circuits_without_calling_llm`).
- **Pattern conformance:** faithfully mirrors `agents/planner.py` — structural `LLMCompleter` Protocol (capability, not a hard `LLMRouter` import → layering preserved), forced `_FORCED_TOOL_CHOICE`, constructor injection, fake-completer tests. The deliberate divergence (raise on malformed vs. planner's fail-soft) is correct here: masking a broken parse as a valid-but-empty CV would be worse than surfacing one typed error to the P5-04 Celery task.
- **Security:** untrusted (user-uploaded) CV text flows in as the user turn; output is constrained to the profile schema and validated, so worst case is garbage-in-profile-fields, not code execution or injection into tools. No secrets, no real network in tests, no `run_python_code`-style execution. Only `LLMError` is caught-and-wrapped, matching the router's error contract (the router wraps its failures in `LLMError`); a non-`LLMError` escaping the completer would propagate as-is, which is consistent with the planner and acceptable.
- **Verification reproduced locally:** `ruff check` (app/ingestion + test) clean; `ruff format --check` 3 files formatted; `mypy app/ingestion/` strict — no issues in 11 files; `pytest tests/test_ingestion_structuring.py` — 15 passed; full suite `pytest -q` — **362 passed, 44 skipped** (matches the report; no new skips/failures).
