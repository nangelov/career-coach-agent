## Notes
- **Access scoping is correct and fails safe** (the security-critical criterion). `_allowed_document_ids` selects `user_id IS NULL` for everyone and `OR user_id = <uuid>` only when `state.user_id` parses to a UUID; a guest (`user_id=None`) or an unparseable id restricts to the shared KB. An explicit id list is *always* passed to `hybrid_search` (never `None` → "no filter"), and an empty allow-list short-circuits before any search — so one user's private CV docs can never leak to a guest or another user. Guest-vs-logged-in scoping is covered by tests (`test_guest_scope_is_shared_kb_only`, `test_logged_in_user_scope_includes_own_docs`, `test_parse_user_uuid_variants`).
- **Fail-soft is sound.** The `except Exception` at rag_agent.py:125 wraps the whole session/embed/search/title block and returns `WorkerResult(error=...)` with empty citations — the node never raises out. Because this runs on Python 3.11+ (`StrEnum` in use), `asyncio.CancelledError` is a `BaseException`, so the broad catch does **not** swallow client-disconnect cancellation. Verified by `test_retrieval_error_fails_soft` and `test_node_without_db_fails_soft`.
- **Reuses the P2-06 primitives correctly** — `hybrid_search` (embed-then-search) with the injected `EmbeddingClient`; no hand-rolled pgvector query. `SearchResult → Citation` mapping (`source_id=str(chunk_id)`, batched parent-title lookup, whitespace-friendly truncation to `SNIPPET_MAX_CHARS`) is faithful, and `content` is a numbered grounding bundle — no LLM synthesis, correctly leaving that to the responder.
- **Graph topology unchanged.** `build_graph` only adds `embedder=`/`db=` DI seams and swaps in a provider-bound `make_rag_node` when supplied (mirroring the P4-03 `router` seam); the module-default `rag_node` binds no pool and fails soft if routed, avoiding a second rogue `from_settings()` pool — honoring the §4 single-shared-pool rule. Edges/reducers/conditional routing untouched.
- **DI/test seams are clean.** `SessionProvider` is a structural `Protocol` (capability, not concrete `PostgresConnectionProvider`); the `_default_embedder` deferred import keeps the ML stack out of import time. Tests inject fakes for both the patched-search contract path and a real-`hybrid_search_chunks`-over-scripted-rows end-to-end path through the compiled graph.
