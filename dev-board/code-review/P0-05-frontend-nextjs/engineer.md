## Key decisions
- **v2 lives in `frontend/` (not `frontend/`).** Per task scope: keep the v1 CRA `frontend/` untouched;
  the rename/cutover to the §8 `frontend/` path is **P11**. Confirmed `git status`/`git diff` show zero
  changes to `frontend/`.
- **Next.js pinned to 15.5.19, not `@latest` (Next 16).** Local/CI runtime is **Node 18.19.1**;
  `create-next-app@latest` installs Next 16 + Tailwind 4 (oxide), both requiring Node >= 20.9 — they fail
  `next typegen`/build here. Next 15.5.x (engines `^18.18.0 || ...`) builds and runs cleanly and still
  satisfies the task's "Next.js 14+". 15.5.19 is the latest 15.5 patch, which clears CVE-2025-66478 present
  in 15.5.4. (Ref: app-design §3 "Next.js (App Router) + React + TypeScript".)
- **Manual scaffold instead of the interactive `create-next-app` wizard** (the wizard invocation was
  declined in this run). All generated files are equivalent to the standard `--typescript --tailwind
  --eslint --app --no-src-dir` output, with versions pinned for Node-18 compatibility.
- **Dev-only proxy.** `rewrites()` returns `[]` outside `NODE_ENV=development` so production routing is left
  to the single-container Dockerfile / reverse proxy (app-design §9 mounts the API under `/api`).
- **React 19** (the React version Next 15 ships with); ESLint 8 + `.eslintrc.json` (stable `next lint` path).
- **Tailwind 3.4** (PostCSS-based) rather than Tailwind 4 (oxide native binary needs Node 20).
