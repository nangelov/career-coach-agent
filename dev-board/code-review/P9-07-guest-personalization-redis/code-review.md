## Notes
- **Acceptance criteria met.** Redis-only store keyed by `session_id` with TTL mirroring the guest-session lifetime (`GUEST_MEMORY_TTL_SECONDS`, default 24h) + bounded memory list (`GUEST_MEMORY_MAX_MEMORIES`). Guest recall reads it via `_recall_guest` returning the same `MemoryContext` shape (no responder change). Guest learn (`GuestPersonalizationLearner`) is Redis-only, never touches Postgres, and applies the **same** `gate_candidate` (P9-04 PII redaction + Art. 9 drop) as the durable path. Upgrade migration (`GuestPersonalizationMigrator`) re-gates on the way in and is best-effort (a failure never breaks the upgrade — mirrors `_backfill`).
- **Security posture is sound.** The §7.6 write-boundary gate is reused (not duplicated) via the newly-public `gate_candidate`, and runs on both the ephemeral write and the durable migration (defense-in-depth verified by `test_migrate_re_gates_special_category_memory`, which seeds Redis directly past the learn gate). No secrets, no arbitrary execution, no untrusted input reaching tools. Guest personalization is session-scoped; no cross-session leakage.
- **Layering respected (§8):** `GuestMemory` ABC in `services/`, `RedisGuestMemory` adapter in `repositories/` over the existing `StoreRedis` seam (no new driver surface), wiring in `bootstrap.py`. Fail-soft posture correct: guest recall degrades to empty `MemoryContext` on any Redis error, guest learn swallows extractor/store errors, `_spawn_guest_learn` handles no-running-loop cleanly and keeps strong task refs.
- **Mutual exclusivity** of logged-in enqueue vs guest learn is correctly keyed on `user_id` and both are gated on `assistant_message.content` and skipped on the cancelled path.
- **Tests are thorough and independently verified green** in the project venv: `test_guest_memory.py` + `test_guest_personalization.py` + `test_memory_agent.py` (41 passed), `test_chat_persistence.py` + `test_guest_upgrade_service.py` + `test_agent_responder.py` (46 passed). Coverage includes: guest recall reads Redis without touching the DB (`FakeSession` asserted untouched), guest learn Redis-only + PII-redact + Art. 9 drop + fail-soft, TTL set/refresh/expiry-reads-empty via a fake KV, migration of prefs+memories with re-gate, malformed-user-id skip, clean no-op, migration-failure-doesn't-break-upgrade, and guest-vs-logged-in learn dispatch.
